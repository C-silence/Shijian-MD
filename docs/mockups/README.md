# 拾简 · 视觉稿 v0.1

本目录是开工前的**静态视觉原型**，用于确认版式层级、配色与元素规范；正式实现为 Compose 原生渲染，尺寸按 dp / sp 落地（原型中 1px ≈ 1dp）。

## 怎么用

- 直接双击 `拾简视觉稿.html` 用浏览器打开；右上角按钮可切换主题。
- 也可在 URL 后加 `?theme=sakura|caramel|mint|dark` 指定主题。

## 评审要点（对照项目设计文档 7.8 元素规范）

1. **标题层级**是否一眼可辨：H1 居中 + 短条 / H2 胶囊 / H3 左竖条 / H4 实心点 / H5 空心点 / H6 短横；
2. **浅色主题下正文、次级文字、标题**的对比与舒适度；
3. **卡片化元素**（引用 / 代码块 / 表格 / 目录 / 属性卡）的圆角、描边、底色浓淡；
4. **纹理强度**（当前为"克制"档，≤ 2%）是否合适，是否需要更淡或关闭；
5. **触摸尺寸**：底部工具条、任务勾选框、列表项的可点范围；
6. **平板三栏**的比例（大纲 212dp \| 编辑 \| 预览）与正文列宽上限（720dp）；
7. **深色版**是否需要更暗或更亮（当前页面底 #1A1B20，主色提亮后 #E58AA6）。

确认或提出修改后，即按项目设计文档第 9 章从 M0 开始实现。
